## Atuação atual

Atualmente, participo de uma atividade de extensão acadêmica voltada ao desenvolvimento de uma solução de software para atender a uma necessidade real de uma empresa. O projeto tem como objetivo entregar essa solução sem custos de desenvolvimento para a empresa beneficiada, aproximando o aprendizado acadêmico de uma experiência prática.

O trabalho é realizado em equipe e segue um processo estruturado de desenvolvimento, incluindo levantamento de requisitos, planejamento, implementação, versionamento de código, testes e documentação. Por se tratar de um projeto privado, seu código e seus detalhes internos não estão disponíveis publicamente.

## Projetos em destaque

### Sistema de vendas desktop

Aplicação desenvolvida em Java para gerenciamento de vendas e persistência de dados em banco relacional.

Principais funcionalidades:

- Autenticação de usuários
- Cadastro de clientes, produtos e categorias
- Edição e consulta de registros
- Registro do fluxo de vendas

**Tecnologias:** `Java` `Maven` `Swing` `SQL`

[Ver repositório](https://github.com/gustavokkj/meucrud)

### Aplicativo Android com Kotlin

Projeto de estudo desenvolvido para praticar os principais componentes do desenvolvimento Android.

Principais funcionalidades:
